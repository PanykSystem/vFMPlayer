# Tape recordings

**SD destination:** `/vFM/recordings/`

No download is required. Tape Recorder saves new captures in the system subfolder after STOP or MOTOR OFF. Recording settings are selected in the Tape Recorder menu.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/recordings)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
