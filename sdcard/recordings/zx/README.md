# ZX recordings

**SD destination:** `/vFM/recordings/zx/`

New ZX TZX captures are saved here. Select ZX/ZX128 compatibility in Tape Recorder. No download is required.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/recordings/zx)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
