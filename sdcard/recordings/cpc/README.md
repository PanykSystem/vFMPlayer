# CPC recordings

**SD destination:** `/vFM/recordings/cpc/`

New CPC CDT captures are saved here. Select CPC compatibility in Tape Recorder. No download is required.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/recordings/cpc)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
