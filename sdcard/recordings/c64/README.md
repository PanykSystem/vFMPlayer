# C64 recordings

**SD destination:** `/vFM/recordings/c64/`

New C64 TAP captures are saved here. Select the correct C64 compatibility in Tape Recorder. No download is required.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/recordings/c64)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
