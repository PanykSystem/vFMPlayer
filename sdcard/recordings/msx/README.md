# MSX recordings

**SD destination:** `/vFM/recordings/msx/`

New MSX CAS captures are saved here. Select MSX compatibility and the desired baud rate in Tape Recorder. No download is required.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/recordings/msx)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
