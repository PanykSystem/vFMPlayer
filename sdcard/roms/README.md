# Optional external drivers

**SD destination:** `/vFM/roms/`

KINROU5.DRV is used for MuSICA/BGM if it is not beside the song. Its original archive, notices and distribution terms are included. SPC700 IPL and other built-in chip ROMs are already in firmware flash; an external SPC ROM is not needed by this Teensy build. See README.txt and /vFM/licenses for external asset sources and terms.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/roms)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
