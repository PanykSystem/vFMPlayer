# Synth presets

**SD destination:** `/vFM/synth/`

Copy the supplied VFS launchers for Felucca, DX7 and Klattsch. Optional Yamaha DX7 bulk SYX dumps can also be placed here. Keep your own presets when updating. VFS files select an engine/preset; they are not MIDI instrument banks.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/synth)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
