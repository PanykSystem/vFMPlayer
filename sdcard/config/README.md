# Saved settings

**SD destination:** `/vFM/config/`

No download is required here. The player creates player-a/b.cfg, clock-a/b.cfg and midi-a/b.cfg automatically. Use the Settings menu to change values. Do not distribute or install another user's binary settings. layout-v1.cfg is an internal import marker.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/config)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
