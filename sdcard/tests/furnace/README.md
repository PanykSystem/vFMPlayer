# Furnace examples

**SD destination:** `/vFM/tests/furnace/`

Optional FUR/DMF test songs may be placed here. This folder may contain only documentation in the base package. Normal Furnace songs can be stored in your music folders.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/tests/furnace)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
