# MIDI examples

**SD destination:** `/vFM/tests/midi/`

Small original MID examples exercise notes, tempo and percussion. MIDI banks must already be installed in /vFM/midi. These are examples, not required resources.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/tests/midi)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
