# Test files

**SD destination:** `/vFM/tests/`

Optional examples and diagnostics. These folders are excluded from ENTIRE SD playback. Browse them explicitly to run tests. Do not put your normal music collection here.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/tests)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
