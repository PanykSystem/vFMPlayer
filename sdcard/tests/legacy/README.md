# Legacy diagnostics

**SD destination:** `/vFM/tests/legacy/`

Reserved for optional older test fixtures imported from .vfm-tests-r55. The public package does not include your personal or commercial music collection. No download is needed for ordinary playback.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/tests/legacy)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
