# Per-track gain

**SD destination:** `/vFM/data/track-gain/`

The player stores each track's MANUAL/AUTO gain records here. Do not edit or share these binary CFG files. No download is required.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/data/track-gain)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
