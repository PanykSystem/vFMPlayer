# MIDI launchers

**SD destination:** `/vFM/midi/instruments/`

VMI files are small text launchers, not sound banks. live.vmi uses the profile chosen in the MIDI menu. Named VMI files can select OPL3_2, OPL3_4, YM2151, YM2413, YM2608 or PSG. Their banks belong in /vFM/midi/banks.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/midi/instruments)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
