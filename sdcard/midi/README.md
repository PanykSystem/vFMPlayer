# MIDI resources

**SD destination:** `/vFM/midi/`

Copy midi.ini, banks and instruments from this repository folder. midi.ini selects the bank files; keep their names and hierarchy. Existing custom midi.ini files should be retained or merged. Use USB MIDI or Serial1 MIDI IN from the MIDI screen.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/midi)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
