# Optional MA3 banks

**SD destination:** `/vFM/midi/banks/MA3/`

Original FITOM FMB resources. Preserve filenames. They are not standalone music files and are used only by compatible bank configurations.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/midi/banks/MA3)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
