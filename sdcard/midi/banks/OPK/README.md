# Optional OPK resources

**SD destination:** `/vFM/midi/banks/OPK/`

Original FITOM instrument resources. Preserve filenames and use them only with a compatible configuration; selecting this folder does not select a player.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/midi/banks/OPK)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
