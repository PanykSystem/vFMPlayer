# OPL3 MIDI banks

**SD destination:** `/vFM/midi/banks/OPL3/`

Copy the supplied BNK/BNK.GZ files. Used by the OPL3_4 MIDI profile and the OPL3 section of midi.ini.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/midi/banks/OPL3)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
