# MIDI banks

**SD destination:** `/vFM/midi/banks/`

Copy the complete banks tree, including the ADPCM sample folders. BNK/BNK.GZ files are instrument resources, not music tracks. midi.ini references these files. The original bank and sample rights remain with their authors; see /vFM/licenses.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/midi/banks)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
