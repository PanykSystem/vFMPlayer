# PSG MIDI banks

**SD destination:** `/vFM/midi/banks/PSG/`

Copy psg.bnk / psg.bnk.gz. Used by the PSG profile and the PSG section of midi.ini.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/midi/banks/PSG)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
