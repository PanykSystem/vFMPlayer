# OPL2 MIDI banks

**SD destination:** `/vFM/midi/banks/OPL2/`

Copy the supplied BNK/BNK.GZ files. Used by the OPL3_2 MIDI profile and the OPL2 section of midi.ini.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/midi/banks/OPL2)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
