# ADPCM samples

**SD destination:** `/vFM/midi/banks/ADPCM/`

Optional FITOM WAV sample resources. Preserve keyboard subfolders and filenames. These are instrument samples, not a general WAV music library.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/midi/banks/ADPCM)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
