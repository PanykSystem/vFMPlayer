# Yamaha PSS-680 samples

**SD destination:** `/vFM/midi/banks/ADPCM/PSS-680/`

Copy the supplied PSS-680 WAV set without renaming its files. Keep it separate from other keyboard sample sets.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/midi/banks/ADPCM/PSS-680)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
