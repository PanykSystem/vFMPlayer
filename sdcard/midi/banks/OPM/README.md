# OPM MIDI banks

**SD destination:** `/vFM/midi/banks/OPM/`

Copy the supplied BNK/BNK.GZ files. Used by the YM2151 profile and the OPM section of midi.ini.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/midi/banks/OPM)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
