# OPLL MIDI banks

**SD destination:** `/vFM/midi/banks/OPLL/`

Copy the supplied BNK/BNK.GZ files. Used by the YM2413 profile and the OPLL section of midi.ini.

[Files and instructions](https://github.com/PanykSystem/vFMPlayer/tree/main/sdcard/midi/banks/OPLL)

Download the repository ZIP and copy the contents of `sdcard` into `/vFM` on the microSD. Keep existing personal settings and recordings. The adjacent `read.me` contains the same essentials in plain text.
